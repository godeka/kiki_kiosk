# kiki_kiosk
키오스크 주문에 어려움을 느끼는 정보 취약계층(ex.노년층)을 위해 주문 단계를 하나씩 나눠 마치 점원과 대화를 나누듯 주문을 진행할 수 있는 키오스크 애플리케이션
